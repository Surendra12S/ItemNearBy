# ItemNearBy

> A simple web app to help users discover items/locations near them (or browse nearby items).  

## 🚀 About  
ItemNearBy is a full-stack project with a frontend and backend. It aims to provide users with an easy way to list, browse and find “items nearby” — whether these are services, goods, or points of interest.  

The repository contains:  
- A **backend** directory: for server-side APIs, data handling, etc.  
- A **frontend/my-app** directory: for the client-side web application UI.
